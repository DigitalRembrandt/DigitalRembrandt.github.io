QuickRock

The image viewer built for speed.

Browse folders containing hundreds of thousands of images in seconds. A professional-grade viewer for macOS — not an editor, just a viewer, done right.

Everything a power user needs.

⚡

Blazing Fast

QuickRock opens a folder of 200,000+ images in just a few seconds. Its bounded memory model never loads the whole library — it stays responsive no matter how large your collection grows.

📸

70+ File Formats

JPEG, PNG, HEIC, WebP, AVIF, JPEG XL, GIF, TIFF, BMP, PSD, TGA, Radiance HDR, and every camera RAW format Apple supports — plus OpenEXR with DWAA and DWAB compression that macOS itself cannot open. Includes a QuickLook extension so EXR files preview in Finder just like any other image.

📁

Powerful File Management

Flag images with a single keypress for batch operations — copy, move, or trash all flagged files at once. Apply Finder color tags on the fly. Copy or move individual files to configured destinations. Undo the last file operation with Cmd+Z. Nine persistent Folder Bookmarks for your most-visited locations.

🔬

Precision Inspection

Live histogram with R/G/B and luminance channels. Exposure control for examining HDR files. Isolate individual RGB channels or view the alpha channel. A/B compare lets you pin one image and flash between it and the current one at the same zoom and pan. Rich metadata and EXIF display. Transparency can be shown against black, white, gray, or a checkerboard.

🗂️

Flexible Viewing

Thumbnail filmstrip for fast visual navigation, a fullscreen thumbnail grid, and clean distraction-free fullscreen viewing. Advanced filtering by name, tag, file type, orientation, date, size, or dimensions — with saveable presets. Sort by name, date, size, or dimensions. Slideshow with six transition types, shuffle, and tag filtering.

🎛️

Fully Customizable

Every keyboard shortcut is reassignable. The shortcut editor lets you search by name, synonym, or description to find exactly what you need. Mouse-click navigation, trackpad gestures, zoom behavior, background color, on-screen controls, file name display — QuickRock adapts to the way you work.

Supported image formats

Standard raster

JPEG & JPEG XL, PNG, GIF, TIFF, BMP, WebP, HEIF/HEIC, AVIF, JPEG 2000, MPO, Netpbm, Adobe Photoshop (PSD), Targa, SGI, QuickDraw PICT, Windows ICO, Apple ICNS

HDR, film & VFX

OpenEXR — all 12 compression schemes including DWAA, DWAB, and HTJ2K via QuickRock's bundled decoder. Opens files that Finder, QuickLook, and Preview cannot. Radiance HDR.

Camera RAW

Adobe DNG, Canon CR2/CR3, Nikon NEF/NRW, Sony ARW, Fujifilm RAF, Panasonic RW2, Leica RWL, Olympus ORF, Pentax PEF, Samsung SRW, Hasselblad 3FR, Phase One IIQ, and more — 17 brands, updated with each macOS release.

GPU textures & specialist

DirectDraw Surface (DDS), Khronos KTX, ASTC, PowerVR (PVR), DICOM medical imaging. Roughly 70 file extensions across 40+ formats total.

Your privacy, by design.

QuickRock collects zero personal data. No analytics, no ads, no tracking. Ever. Your files and metadata never leave your Mac.
